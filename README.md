# Stock Management – Veen Moda

A web-based stock management system built with Laravel to manage fabric inventory and support daily operations at Veen Moda.

## Features
- Role-based authentication (Admin & Staff)
- Fabric and product management
- Incoming goods (stock in) management
- Stock monitoring system
- Staff account management
- Activity log for tracking user actions

## Tech Stack
- Laravel
- PHP
- MySQL
- HTML, CSS, JavaScript

## Purpose
This project was developed to help improve stock accuracy and streamline inventory management processes in a fabric retail business.
